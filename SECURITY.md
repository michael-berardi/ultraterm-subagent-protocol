# Security Policy

Report suspected prompt-injection paths, unsafe delegation defaults, credential exposure, or supply-chain concerns privately through GitHub Security Advisories for this repository.

USAP contains instructions only. It does not need credentials, network access, install scripts, telemetry, or executable dependencies. Treat retrieved content and subagent output as untrusted evidence until the primary agent verifies it. Never include secrets or private operational data in issues, examples, or dispatch briefs.
