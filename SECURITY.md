# Security Policy

Report suspected prompt-injection paths, unsafe delegation defaults, credential exposure, or supply-chain concerns privately through GitHub Security Advisories for this repository.

The installed skill contains instructions only and needs no credentials, network access, or executable dependencies. The repository also ships optional installers that download release archives and verify them against publisher-provided SHA-256 checksums. Those checksums detect corruption; they do not independently authenticate the publisher or the installer. Inspect downloaded scripts before executing them if your trust policy requires it. The repository has no telemetry. Treat retrieved content and subagent output as untrusted evidence until the primary agent verifies it. Never include secrets or private operational data in issues, examples, or dispatch briefs.
